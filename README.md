# Notas de Redes Neuronales y Prácticas de Inteligencia Artificial

Este repositorio contiene la colección de prácticas y ejercicios desarrollados en Google Colab para la asignatura de **Inteligencia Artificial** de la **Universidad Nacional Rosario Castellanos**. El objetivo es documentar la implementación y el entendimiento de los principales modelos de redes neuronales, desde los perceptrones básicos hasta arquitecturas modernas.

El contenido sigue la estructura del curso cubriendo: **Fundamentos de IA, Arquitecturas Clásicas y Arquitecturas Modernas de Redes Neuronales.**

---

## Tecnologías y Herramientas

Las prácticas fueron implementadas utilizando el ecosistema de **Python**, aprovechando la aceleración por GPU de Google Colab.

| Tecnología | Rol |
| :--- | :--- |
| **Python** | Lenguaje de programación principal. |
| **TensorFlow / Keras** | Construcción, entrenamiento y evaluación de modelos de Redes Neuronales. |
| **NumPy** | Manipulación eficiente de tensores y operaciones matriciales. |
| **Pandas** | Carga y preprocesamiento de *datasets*. |
| **Matplotlib / Seaborn** | Visualización de datos y resultados de entrenamiento. |

---

## Contenido de las Prácticas

A continuación, se detallan los temas principales cubiertos en los *notebooks*, reflejando el progreso a través del curso:

### I. Fundamentos y Neuronas 
* **Introducción a la IA y Machine Learning:** Definiciones y diferencias clave.
* **Neuronas Artificiales:** Implementación de la neurona de McCulloch y Pitts y el Perceptrón.

### II. Redes Neuronales Clásicas y Entrenamiento 
* **MLP (Multi-Layer Perceptron):** Uso de redes densas para problemas de regresión y clasificación.
* **Backpropagation:** Entendimiento del algoritmo de propagación hacia atrás.
* **Métricas y Optimización:** Uso de funciones de pérdida, optimizadores (SGD, Adam) y métricas (Accuracy, etc.).

### III. Arquitecturas Modernas 

| Tema | Descripción | Enfoque |
| :--- | :--- | :--- |
| **Redes Convolucionales (CNN)** | Implementación de capas de convolución, *pooling* y filtros para la extracción de características. | Procesamiento de Imágenes (CV) |
| **Neuronas Recurrentes (RNN)** | Introducción al procesamiento de secuencias, manejo de memoria (estados ocultos) y temporalidad. | Datos Secuenciales (NLP, Series de Tiempo) |

## Cómo Ejecutar las Prácticas

Dado que estos archivos son **Google Colab Notebooks** (`.ipynb`), no es necesario instalar dependencias localmente.

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/tu_usuario/tu_repositorio.git](https://github.com/tu_usuario/tu_repositorio.git)
    ```
2.  **Abrir en Colab:**
    Simplemente navega hasta el archivo `.ipynb` deseado en el repositorio de GitHub y haz clic en el botón "Open in Colab" (o sigue la URL de Colab e importa el archivo desde GitHub).

3.  **Ejecutar:**
    Una vez abierto, puedes ejecutar las celdas secuencialmente para ver el código, los resultados y las visualizaciones.
